---
topic: clarification pattern for ambiguous tech requests
---

When a user asks an ambiguous technical request (e.g., "unable to use HDMI ports on the TV, need to get those mapped"):

1. Offer concrete multi-select choices (task type, affected ports, failure mode, environment/repo state) instead of open-ended "what do you mean?"
2. Keep it brief — no long explanations.
3. If the user responds with uncertainty ("I don't actually know, the post is just listed as unavailable"), pivot to a content/documentation interpretation rather than inventing a hardware/app fix.
