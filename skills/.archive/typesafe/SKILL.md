# TypeSafe

Use when building with TypeSafe AI primitives (Choice, Noul, Score). 
TypeSafe makes units of AI intelligence usable like programming primitives: small judgments you can compose into larger capabilities.

## Workflow
1. Start from desired app behavior; work backward to judgments needed.
2. Choose primitive: Choice (set), Noul (condition), Score (dimension).
3. Design narrow, coherent questions with sufficient state.
4. Compose parallel questions; verify with probability/confidence thresholds.
5. Use live docs for current API/SDK details.
