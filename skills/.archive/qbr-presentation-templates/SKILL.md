# QBR Presentation Templates

## Slide Structure

### 1. Executive Summary
- Key metrics: ARR, NPS, usage growth
- Wins: new use cases, feature adoption
- Risks: support trends, usage decline
- Next steps: expansion opportunities, recommendations

### 2. Business Value Realized
- ROI calculations based on usage and cost savings
- Customer quotes/testimonials (from HubSpot notes)
- Industry benchmarks comparison

### 3. Product Adoption & Usage
- Monthly active users trend (Amplitude)
- Feature adoption heat map
- Power user identification
- Comparison to previous quarter

### 4. Project Health (Edge Impulse)
- Active deployments and uptime
- Model performance metrics
- Data pipeline status
- Resource utilization trends

### 5. Success Themes
- Training and enablement completed
- Support ticket resolution times
- Advocate/champion development
- Community contributions or references

### 6. Roadmap & Recommendations
- Recommended next features/buy-ons
- Training opportunities identified
- Technical debt to address
- Expansion timeline suggestions

### 7. QBR Feedback & Action Items
- Product feedback captured
- Support issues to resolve
- Next quarter objectives
- Follow-up owner assignment

## Automation Hooks
- Pull live charts from Amplitude
- Embed Edge Impulse deployment dashboards
- Sync recent HubSpot activities automatically
- Generate PDF or PowerPoint output

## Customization Options
- Industry-specific benchmarks
- Company-size tailored comparisons
- Role-based (executive vs technical) versions
- Multi-language support
