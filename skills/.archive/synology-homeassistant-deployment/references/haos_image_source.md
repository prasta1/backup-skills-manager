# HAOS Image Source Guide

## Repository
The canonical source for HAOS OVA files is the `home-assistant/operating-system` repository on GitHub.

## Asset Pattern
The required file is an OVA package, typically named following this pattern: `home-assistant-os-18.x-x-x-*.ova`

## Verification
The download must be verified against the SHA256 digest provided in the GitHub release assets to prevent corrupted deployments.
