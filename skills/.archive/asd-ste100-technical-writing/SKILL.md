# ASD-STE100 Technical Writing

Apply Simplified Technical English rules to ensure clarity and consistency in technical documentation.

## Core Rules

### Vocabulary Constraints
- Use only the 2,500-approved word dictionary (ASD-STE100 list)
- General words (time, date, day) are always allowed
- Technical words are allowed if defined in your company's dictionary
- Avoid synonyms - use the same word consistently for the same thing
- Do not use abbreviations, initials, or acronyms without defining them

### Grammar Rules
- One verb per sentence (do not combine actions)
- Use active voice. Passive voice only when the actor is unknown or unimportant
- Do not use articles (a, an, the) before technical nouns
- Do not use "and" or "or" to connect two nouns in a series
- Write in the present tense
- Use "warning words" (caution, danger, note, warning) correctly

### Style Patterns
- Write short sentences (under 25 words)
- Use clear noun clusters (25 words max, "nose-verbs" avoided)
- State one instruction per paragraph
- Use tables or lists for complex information

## Implementation

When this skill is loaded, apply these rules to all technical writing:
1. Check vocabulary against approved list
2. Split compound sentences
3. Remove articles before technical nouns
4. Define all technical terms on first use
5. Use active voice consistently
