# Definitions Pattern for Community Education

Use this pattern in the first session on any technical topic, especially AI or related technical subjects intended for a general audience.

## Rule
Open the session with definitions before explanations. Keep jargon underwater until after this block.

## Format
Write each entry as:
**word** — one-sentence plain-language definition. Not X.

## Example block from M1
- **AI** — Artificial Intelligence. Any system that makes decisions or predictions based on patterns in data. Not a thinking machine. Not a person.
- **ML** — Machine Learning. The subset of AI that learns patterns from examples instead of being explicitly programmed for every rule.
- **LLM** — Large Language Model. An ML system trained on enormous amounts of text that predicts what words should come next.
- **Agent** — An AI system that doesn't just chat but can take actions: run searches, send messages, control other tools.
- **Model** — The trained result of an ML system.
- **Parameters** — The internal values a model uses to make predictions.
- **Prompt** — The text you give an AI to tell it what you want.
- **Hallucination** — When an AI confidently says something that isn't true.
- **Local vs cloud** — Local runs on your own machine; cloud runs on someone else's computers.

## Teaching notes
- Keep each definition to one sentence
- Include "Not X" in items that carry common misconceptions
- Use handouts to make the definitions portable
- In later sessions, you can reference this block briefly instead of repeating it
