# Module archetypes

Reference the matching archetype when drafting or reviewing a session.

- **Foundation (`m1`)** — vocab block first, relatable hook, one main concept, fear reducer with 2–3 named fears, live demo showing capability and a clean failure, handout with carry-forward vocabulary.
- **Conceptual (`m2`)** — short recap, one conceptual leap with metaphor, local examples, brutal honesty about limitations, live demo showing failure modes, fear reducer for the new fear.
- **Hands-on (`m3`)** — minimum setup in plain language, honest requirements, concept preview, live demo on real hardware, stated fallback plan, low-bar next action.
- **Practical skill (`m4`)** — one skill, pattern taught with bad/good/result examples, attendee practice with feedback, guardrails, one-page cheat sheet.
- **Applied (`m5`)** — mental filter first, local examples, group activity naming real tasks, live prompts from the room, practical Q&A.
- **Closing policy (`m6`)** — recap, privacy/tradeoff framing, evaluation checklist, long open Q&A, durable decision frame.
